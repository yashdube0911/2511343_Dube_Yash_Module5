# What is convolution?

Convolution is a process where filters move across an image to detect important visual patterns such as edges, shapes, textures, and defects.

# Why is pooling used?

Pooling is used to reduce the size of feature maps. This helps reduce computation, speeds up training, and helps prevent overfitting.

# Why is ReLU commonly used in CNNs?

ReLU is commonly used because it helps the neural network learn complex patterns efficiently while improving training speed and performance.

# Why are CNNs better than regular feed-forward networks for image data?

CNNs are designed specifically for image processing. They automatically learn spatial features and patterns from images while using fewer parameters compared to regular feed-forward neural networks.
